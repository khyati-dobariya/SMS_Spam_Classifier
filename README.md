SMS Spam Classifier

Project Overview

SMS Spam Classifier is a Machine Learning project that classifies SMS messages into two categories: Spam and Ham (Not Spam).

The main objective of this project is to identify unwanted or fraudulent SMS messages using Machine Learning techniques.

Features

- Classifies SMS messages as Spam or Ham.
- Text preprocessing and cleaning.
- Converts text messages into numerical features using a vectorizer.
- Uses a trained Machine Learning model for prediction.
- Provides predictions through a Python application.

Technologies Used

- Python
- Machine Learning
- Pandas
- Scikit-learn
- NLP (Natural Language Processing)
- Jupyter Notebook

Dataset

This project uses the SMS Spam Collection Dataset, which contains SMS messages labeled as Spam or Ham.

Project Files

- "SMS-Spam-Classifier.ipynb" – Jupyter Notebook containing data preprocessing, model training, and evaluation.
- "app.py" – Python application for SMS classification.
- "model.pkl" – Saved trained Machine Learning model.
- "vectorizer.pkl" – Saved text vectorizer.
- "spam.csv" – SMS Spam Collection dataset.

How to Run the Project

1. Clone this repository.
2. Install the required Python libraries.
3. Run the application using Python.

Project Goal

To build a Machine Learning-based SMS spam detection system that helps identify unwanted and potentially fraudulent messages.
